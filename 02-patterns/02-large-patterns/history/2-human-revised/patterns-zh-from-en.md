# 面向洪水风险管理的水库调度调整：基于50篇论文的推理与执行归纳

我们分析了50篇关于面向洪水风险管理的水库调度调整的论文。对于每篇论文，我们提取了研究问题、作者作出选择背后的推理，以及用于实施和评价其方法的执行流程。平均每篇论文提取了6.9个推理步骤，用于描述作者如何界定问题并论证决策；以及8.3个执行步骤，用于描述作者如何准备输入、开发和应用方法并评价结果。随后，我们比较了不同论文中的步骤，将功能相近的内容归纳为8个初步推理模式和11个初步执行模式。下表汇总了这些模式，为后续技能开发与测试提供起点。

## 1. 推理

| 候选类别 | 共同回答的问题 |
|---|---|
| 诊断洪水风险下现行水库调度规则的局限 | 在什么条件下，现行水库调度规则无法兼顾洪水风险管理与其他水库运行目标？哪些局限表明有必要调整规则？ |
| 识别影响洪水风险与水库调度决策的不确定性 | 哪些预报误差、洪水演变中的不确定性，以及不确定性来源之间的依赖关系，可能影响水库调度决策和洪水风险？ |
| 判断水库防洪调度所需预报的可靠性与时序 | 在与决策相关的时间范围内，现有洪水预报有多可靠？这些预报能在洪水事件的不同阶段支持哪些水库调度决策？ |
| 论证水库与下游洪水风险的界定及可接受安全边界 | 应如何界定不安全的洪水后果？应如何为水库及下游地区确定可接受风险水平或安全阈值？ |
| 判断水库调度调整的物理与运行可行性 | 预报提前量是否足以支持水库调度调整？可用库容和泄流能力是否充足？能否在不违反下游安全约束的前提下实施调整？ |
| 明确水库调度的目标权衡与方案选择原则 | 在比较不同调度方案时，应如何考虑水库安全、下游洪水风险与其他运行目标之间的冲突？ |
| 考虑洪水事件不同阶段的适应性水库调度 | 随着洪水状况和预报变化，应在何时调整或重新规划水库调度？应在何时从预泄转向防洪调度或回蓄？ |
| 判断水库调度调整的证据与适用性 | 如何评价预报对调度的价值？安全与效益方面的证据支持哪些结论？这些结论适用于哪些水库和洪水条件？ |

## 2. 执行

| 候选类别 | 共同完成的任务 |
|---|---|
| 准备水库调度数据与基线规则 | 汇集水文、蓄水、泄流及下游控制数据；明确初始条件和调度时域；将现行调度规则设为比较基线。 |
| 构建并检验洪水与入库流量预报 | 准备气象和水文输入，构建洪水与入库流量预报，并评价其在水库调度所需预见期内的准确性。 |
| 建模调度不确定性并生成可能情景 | 表示预报误差及其他调度不确定性，考虑它们之间的重要依赖关系，为水库调度与风险分析生成合理情景。 |
| 模拟不确定性下的水库与下游洪水响应 | 利用水库和河流系统模型，模拟入流情景与调度决策如何影响库水位、蓄水量、泄流量、下游流量及洪水风险。 |
| 计算调度安全边界并检查可行性 | 将库容、泄流能力、预报提前量和安全要求转化为可行的调度边界，并检查候选泄流或水位方案是否满足这些边界。 |
| 求解候选调度方案与规则参数 | 运用优化、解析推导、枚举或参数校准，确定候选水库调度策略的泄流安排、蓄水目标、运行水位或规则参数。 |
| 计算候选调度方案的风险、损失与效益 | 对每个候选调度方案，计算水库与下游洪水风险、潜在洪灾损失，以及与其他水库运行目标相关的效益。 |
| 组织评价指标并选择调度方案 | 确定并组织安全、风险与运行效益的评价指标，考虑各指标的相对重要性，比较可行的调度方案。 |
| 将调度结果转化为分阶段行动并滚动更新 | 将调度方案转化为不同洪水阶段的泄流或水位目标，并随着水库状态和预报变化更新这些行动。 |
| 比较并检验水库调度策略 | 将候选策略与现行规则或其他方法比较，并检验其在不同预报、洪水事件、调度时域和参数设置下的表现。 |
| 开展调度会商、试点实施与规则修订 | 对于涉及管理实践的研究，与相关利益方共同审议拟议的调度调整，在可行时通过试点实施进行检验，评价其表现，并据此修订调度规则或指导文件。 |
