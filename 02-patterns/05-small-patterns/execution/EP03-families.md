# EP03 小 pattern：不确定性建模与情景生成

日期：2026-10-01 | 状态：已定稿 | 编码者：Claude Code | 方法同 [`../reasoning/RP01-families.md`](../reasoning/RP01-families.md)

**大 pattern 任务：** 怎样把与决策相关的不确定性，转成可以用于模拟和优化的情景？

**证据：** EP03 的全部匹配：85 步，36 篇论文（primary 62，secondary 23）。逐条分配见 [`EP03-assignment.csv`](EP03-assignment.csv)。

## 2. 小 pattern 定义

### EP03-A 设定或拟合误差与变量的分布
- **触发条件：** 预报误差、起调状态或水文变量需要用概率（或模糊）方式表示。
- **要做的工作：** 构造误差变量（相对误差、更新增量），按需要分季节或分预见期；拟合候选分布并检验；数据有限时，由合格率或 NSE 推出误差分布。
- **产出：** 可抽样的分布及检验结果。
- **代表证据：** E04-E3、E04-E4（分季节、筛选边缘分布）；E42-E2（混合分布）；E36-E2（由精度指标反推）。

### EP03-B 在生成时保留相依
- **触发条件：** 不同时刻、站点、变量或成员之间不能独立抽样。
- **要做的工作：** 拟合 copula 或 VAR，用条件分布、Schaake 重排或 Gibbs 抽样生成具有相关性的序列。
- **产出：** 相关结构一致的样本。
- **代表证据：** E13-E5、E13-E6、E34-E2。

### EP03-C 生成预报情景与集合
- **触发条件：** 模拟或优化需要一组有限、但能覆盖可能未来的入流。
- **要做的工作：** 扰动预报或实测序列、按分布抽样，或重建合成集合预报；给各情景赋予概率。
- **产出：** 情景集或集合，以及各自的概率。

### EP03-D 生成或放大设计洪水与随机洪水事件
- **触发条件：** 历史记录中的大洪水太少，或者需要评估预见期以外的风险。
- **要做的工作：** 构建随机洪水模型、按重现期放大典型洪水、按预见期之差对齐设计洪水、生成非平稳情景。
- **产出：** 设计洪水或随机洪水事件集。
- **代表证据：** E16-E7（放大到 100–300 年一遇）；E20-E2（1,000 场随机暴洪）；E33-E7（多站点洪水，保留遭遇特性）。

### EP03-E 把集合缩减为情景树
- **触发条件：** 完整集合太大，无法用于多阶段优化。
- **要做的工作：** 用缩减算法保留代表性分支，并保持概率加权的总量不变。
- **代表证据：** E23-E3、E35-E7、E36-E3。

### EP03-F 把预报以外的不确定性写进水量平衡
- **触发条件：** 起调库容、泄流能力、库容曲线、风浪，或者状态本身是随机的。
- **要做的工作：** 把这些量写成随机变量或随机过程，放进水量平衡计算。
- **代表证据：** E06-E5、E08-E1、E30-E1。

### EP03-G 检验生成的情景是否保真
- **触发条件：** 情景要用于风险结论，必须先证明它们和真实情况相符。
- **要做的工作：** 比较统计量、覆盖率、相关矩阵和极端事件属性。
- **代表证据：** E13-E9、E13-E10、E42-E5。
- **与 EP02-D 的边界：** EP02-D 检验预报产品本身；EP03-G 检验由误差模型生成的情景。两者在合成预报（E13）上有交叉。
