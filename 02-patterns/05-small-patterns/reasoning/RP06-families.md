# RP06 小 pattern：权衡目标与选择原则

日期：2026-10-01 | 状态：已定稿 | 编码者：Claude Code | 方法同 [`RP01-families.md`](RP01-families.md)

**大 pattern 问题：** 防洪安全、供水、蓄水、发电等目标无法同时做到最好时，用什么原则来选择？

**证据：** RP06 的全部匹配：84 步，40 篇论文（primary 56，secondary 28）。逐条分配见 [`RP06-assignment.csv`](RP06-assignment.csv)。分组依据是"在取舍中要做哪一种判断"。

## 2. 小 pattern 定义

### RP06-A 识别相互冲突的目标
- **触发条件：** 一个调整同时影响防洪安全和其他目标，或者影响两个不同的安全对象。
- **识别后要做的事：** 列出所有受影响的目标，说清楚冲突的方向，即一方变好时另一方如何变坏。
- **预期产出：** 冲突目标清单及冲突机制。
- **代表证据：** E22-R3（削减洪峰与保留库容）；E02-R3（降低库水位保护大坝，但要多放水，下游受威胁）；E21-R2（防洪、发电、航运、生态、输电）。
- **与 RP01-A 的边界：** RP01-A 是"现有规则造成的失衡"；RP06-A 是"目标本身的冲突"，不一定针对现行规则。

### RP06-B 在时间或系统上分配有限资源
- **触发条件：** 同一份库容或过流能力，要在不同时段之间、或不同水库之间分配。
- **识别后要做的事：** 比较多给一方一个单位资源的边际价值，找出分配的区间和切换点。
- **预期产出：** 分配原则及对应的条件区间。
- **代表证据：** E03-R3（剩余容量在当前蓄水与未来安全裕度之间分配）；E24-R1（当前与未来争用过流能力）；E21-R5（上游富余库容替下游分担）。

### RP06-C 安全优先：先划安全域，再优化效益
- **触发条件：** 安全风险不能用其他效益抵消。
- **识别后要做的事：** 把风险或安全阈值设为约束，只在满足约束的方案中追求发电、蓄水等效益；如果另一种安全度量超标（例如 CVaR），就追加约束。
- **预期产出：** "安全约束 + 效益目标"的结构。
- **代表证据：** E33-R7、E45-R4、E45-R5、E50-R5。

### RP06-D 多目标没有唯一最优，保留非劣解集
- **触发条件：** 目标之间存在冲突，任何一个方案都不能在所有目标上同时最好。
- **识别后要做的事：** 保留非劣解集；只有当目标量纲可比时才加权聚合，并把聚合结果放回非劣解集中检查（E20-R6、E20-R9）；挑出有代表性的方案并解释它们的运行含义。
- **预期产出：** 非劣解集，以及代表性方案的解释。

### RP06-E 最终选择取决于偏好与排序规则
- **触发条件：** 非劣解集中有多个合理方案，必须选一个。
- **识别后要做的事：** 明确偏好的来源，例如权重、专家判断或部门协商；对指标先做筛选或去相关，再排序；说明结果对权重的敏感程度。
- **预期产出：** 选择规则、权重假设和选出的方案。
- **代表证据：** E02-R7（准则值和权重都不确定时的随机多准则选择）；E21-R6（多部门协商确定方案）；E47-R1（先筛选准则，再排序）。
- **与 EP08 的边界：** RP06-E 决定"按什么原则选"；EP08 去执行排序计算。

### RP06-F 目标的设定要贴合问题
- **触发条件：** 目标函数里放什么，会直接改变答案。
- **包含：** 小洪水只看水位和泄量，大洪水要加入失事概率、持续时间、损失（E14）；加入洪水过程的韧性（E12）；加入防止过度腾库的惩罚项（E16）；按场地用途设定目标（E18）；区分评价用的风险指标和运行模型内部的目标（E20-R7）；分阶段设定目标（E46）。
- **识别后要做的事：** 说明目标函数每一项对应的关切，以及为什么这样设而不是那样设。
- **预期产出：** 目标函数的构成及理由。

## 3. 区分规则

| 主要在说…… | 主小 pattern |
|---|---|
| 哪些目标在冲突 | A |
| 有限资源在时间或空间上怎么分 | B |
| 安全不可让步，效益在其内优化 | C |
| 保留多个非劣方案 | D |
| 用什么偏好规则选出一个 | E |
| 目标函数应该包含什么 | F |
