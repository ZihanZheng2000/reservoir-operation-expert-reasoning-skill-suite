## 2. 小 pattern 定义

### RP04-A 定义库区一侧的失事事件
- **触发条件：** 需要把调度结果变成"安全或不安全"的判断，研究对象主要是水库本身。
- **识别后要做的事：** 选择描述后果的变量，例如最高水位、最大占用库容、所需防洪库容；设定对应的安全阈值，例如校核水位或防洪高水位；把风险定义为超过阈值的概率。
- **预期产出：** 风险事件、所用变量和阈值的定义。
- **代表证据：** E06-R1（荷载超过抗力）；E36-R6（最高水位超过安全水位的概率）；E17-R3（以所需防洪库容为安全度量）。

### RP04-B 定义下游与工程后果
- **触发条件：** 水库调度的主要后果发生在下游或工程结构上。
- **包含：** 堤防失事概率（E10、E24）；溃坝条件概率与损失（E20）；漫顶与岩土破坏的易损性曲线（E25）；超过安全泄量的惩罚（E35、E50）；洪水与少发电两条后果路径（E42）；保留缓冲后的下游安全水位（E43）。
- **识别后要做的事：** 把水库泄量或水位与具体保护对象的后果联系起来，例如河道能力、损失函数、易损性。
- **预期产出：** 保护对象、后果函数和阈值。

### RP04-C 一个超阈概率不够，要补充其他度量
- **触发条件：** 只用超阈概率，会看不到超过阈值以后损失有多大、持续多久、能否恢复。
- **识别后要做的事：** 在概率之外加入损失、CVaR、熵、持续时间或韧性等度量，并说明各自补上了什么信息。
- **预期产出：** 一组互补的风险度量，以及选择理由。
- **代表证据：** E38-R2（均值、CVaR、熵三者互补）；E45-R5（概率已达标但 CVaR 超标，因此增加约束）；E49-R3（概率、损失、持续时间同时考虑）。

### RP04-D 设定可接受风险的基准
- **触发条件：** 算出了风险，还需要判断这个数值能否接受。
- **包含：** 不高于现行规则在设计洪水下的风险（E01）；防洪标准或设计洪水频率（E33、E40）；平稳期方案作为上限（E45-R3）；临界库容（E22）；PMF 检验（E46）；在接受与不接受之间作出判断，并交代比较的局限（E27-R6）。
- **识别后要做的事：** 选择一个有依据的比较对象作为通过线，并说明这个依据从哪里来。
- **预期产出：** 通过 / 不通过的判据及其来源。

### RP04-E 由可接受风险反推调度边界
- **触发条件：** 已经有了可接受风险，需要把它变成可以操作的量。
- **包含：** 反推最小安全裕度（E03）；必须容纳的来水分位数（E15）；可允许的预报误差（E11）；控制水位和预留库容（E30）；不超过标准的最高起调水位（E39、E41）；风险超标时修改方案或启动应急措施（E31）。
- **识别后要做的事：** 解出"风险刚好等于上限"时的调度量，并说明它对其他假设的敏感程度。
- **预期产出：** 由风险上限推出的水位、库容或泄量边界。
- **与 RP05 的边界：** RP05 的边界来自物理能力，例如泄流能力和预见期；RP04-E 的边界来自风险上限。

### RP04-F 多个安全对象或阈值同时存在
- **触发条件：** 大坝与下游的风险此消彼长，或者多座水库、多个控制点都要保证安全。
- **识别后要做的事：** 分别定义各个对象的风险；说明合并方式（并、交、加权或分层），以及谁优先。
- **预期产出：** 多对象风险的结构和合并规则。
- **代表证据：** E39-R2（单一、并集、交集三种失事事件）；E40-R3（控泄或控水位分别暴露下游或上游风险）；E38-R4（先给各水库定权重，再汇总为系统风险）。

### RP04-G 风险在时间上的汇总
- **触发条件：** 风险会在洪水过程的任何时刻出现，延续到预见期以外，或者只是在某场设计洪水条件下的条件概率。
- **识别后要做的事：** 区分单个时点的风险与全过程的风险，避免重复计数；把预见期外的风险补上；用洪水发生概率把条件风险换算成年化风险。
- **预期产出：** 时间维度上的风险汇总方式。
- **代表证据：** E30-R5、E31-R2（单点与全过程）；E40-R2、E33-R2（预见期内与预见期外）；E28-R4、E37-R6（乘以洪水发生概率）。

## 3. 区分规则

| 主要在说…… | 主小 pattern |
|---|---|
| 水库本身什么状态算不安全 | A |
| 下游或工程结构的后果 | B |
| 除了概率还要什么度量 | C |
| 多大风险可以接受，依据是什么 | D |
| 由风险上限算出调度量 | E |
| 多个对象或阈值怎么合并 | F |
| 时间上怎么汇总 | G |
