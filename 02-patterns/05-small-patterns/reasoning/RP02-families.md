# RP02 小 pattern：识别影响决策的不确定性

日期：2026-10-01 | 状态：已定稿 | 编码者：Claude Code | 方法同 [`RP01-families.md`](RP01-families.md)

**大 pattern 问题：** 哪些不确定性会改变放水、蓄水、风险或规则选择，因而必须表示出来？

**证据：** RP02 的全部匹配，73 步、35 篇论文（primary 57，secondary 16）。逐条分配见 [`RP02-assignment.csv`](RP02-assignment.csv)。分组依据是"关于不确定性要做哪一种判断"。

## 2. 小 pattern 定义

### RP02-A 预报不确定性必须进入决策

- **触发条件：** 调度在洪水发生前根据预报行动，而预报有误差。
- **包含：** 低估会导致防洪库容不足、下泄偏大，高估会导致无谓弃水；单一确定性预报无法对冲；只看确定性预报会让方案显得比实际更可靠。
- **不包含：** 误差具体是什么形状（D）、彼此如何相关（E）。
- **识别后要做的事：** 说明预报偏高和偏低分别会造成什么后果，要求用概率、集合或情景来表示预报，而不是单一预报。
- **预期产出：** "预报误差会如何导致错误决策"的说明，以及采用概率化输入的要求。
- **代表证据：** E22-R1（低估与高估代价相反）；E35-R3（单一轨迹无法对冲未消除的不确定性）；E36-R1（忽略不确定性会让方案显得过于确定）。

### RP02-B 不确定性不只来自预报

- **触发条件：** 结果还受其他随机因素影响，例如起调水位、洪水过程形状、泄流系数、库容曲线误差、回水和风浪。
- **包含：** E01（洪水过程形状）、E06（泄流、库容、风浪）、E08 / E20（起调库容）、E31（出流和库容误差）、E09（无雨期长度）、E39（洪量）。
- **不包含：** 只讨论预报误差的情况（A、D、E）。
- **识别后要做的事：** 列出预报以外可能影响水位和泄量的因素，判断哪些需要与预报误差一起表示。
- **预期产出：** 一张包含非预报来源的不确定性清单。
- **代表证据：** E06-R5、E08-R2、E31-R1。

### RP02-C 只保留决策相关的来源，并说明排除

- **触发条件：** 可能的来源很多，全部建模不可行或数据不足。
- **包含：** 只选起调水位和预报误差，明确排除泄流和库容曲线（E08）；因为没有降雨预报，只表示水文不确定性（E29）；判断预报净雨误差最重要且最可处理（E37）。
- **识别后要做的事：** 按"能否改变决策"和"能否处理"排序，写清保留了什么、排除了什么、为什么排除。
- **预期产出：** 带排除理由的范围说明。
- **代表证据：** E08-R1、E29-R2、E37-R2。

### RP02-D 误差结构不是一个固定分布

- **触发条件：** 误差的大小、偏差或形状随预见期、流量、季节变化，或者明显非正态、多峰、带模糊性；历史样本也可能覆盖不到罕见的误差模式。
- **包含：** E04（非平稳、非正态，分季节拟合）；E27（只在高流量时才近似平稳）；E35（随预见期增大，涨水段更大）；E42（多峰混合分布）；E41（模糊性）；E12（用全分布替代极端误差规则）；E13-R1（短回报期漏掉罕见模式）。
- **不包含：** 误差之间的相关性（E）。
- **识别后要做的事：** 检查误差分布是否随条件变化，不要假设单一的平稳正态分布，并对拟合做检验。
- **预期产出：** 按条件划分的误差描述和检验结果。
- **代表证据：** E04-R4、E35-R4、E42-R1。

### RP02-E 误差之间存在相依

- **触发条件：** 误差在时间（相邻时段、各预见期）、空间（上游与区间、多座水库）、变量或集合成员之间相关，或者在极端值处相依。
- **包含：** copula、协方差项、成员间相关、洪水过程的序列相依等。
- **识别后要做的事：** 检查相关性是否显著，判断忽略它会低估还是高估联合风险，决定保留哪些相依。
- **预期产出：** 需要保留的相依结构及其理由。
- **代表证据：** E24-R2（上游与区间误差相加时，协方差可能放大风险）；E13-R4（逐成员独立处理会丢失成员间相关）；E30-R4（相邻时刻的协方差进入水位方差）。

### RP02-F 只有精度指标或确定性预报时，要换算成概率分布

- **触发条件：** 没有完整的集合预报，只有预报合格率、NSE / R²，或者一个确定性预报。
- **包含：** 由合格率或 NSE 反推正态误差的标准差（E01、E28、E36）；把点预报转成条件概率分布（E15）；由拟合的误差模型生成集合，并检验覆盖率（E42-R4）。
- **识别后要做的事：** 说明换算所需的假设，例如零均值正态，并在可能时检验覆盖率。
- **预期产出：** 可用于抽样的误差分布及其假设。
- **代表证据：** E28-R2、E36-R2、E15-R2。

### RP02-G 追踪不确定性如何传到水位、泄量和风险

- **触发条件：** 需要知道输入误差经过演算、规则和优化之后，在哪里、以多大程度影响结果。
- **包含：** 预报→优化→决策的链条（E02）；经规则演算传到水位（E06、E27）；分阶段传到期末库容和缺水（E26）；跨时段、跨水库传递（E32）；不确定性何时被新信息消除（E23-R3）。
- **识别后要做的事：** 画出传播路径，标明放大或抵消的环节，以及信息更新的时间点。
- **预期产出：** 不确定性传播路径图或说明。
- **代表证据：** E02-R1、E26-R2、E32-R1。

### RP02-H 不确定性大小会改变最优决策

- **触发条件：** 决策对误差大小敏感，存在临界值，超过它最优策略就会改变。
- **包含：** 误差与可接受风险决定最小安全裕度（E03-R4）；误差大小决定对冲区间（E03-R7、E24-R5）；误差超过阈值后，增加蓄水已失去意义（E05-R6）。
- **识别后要做的事：** 找出临界的误差大小，并说明在临界值两侧的决策分别是什么。
- **预期产出：** 误差阈值与对应的决策分支。
- **证据说明：** 4 步均为 secondary，主要来自解析对冲模型类论文。

## 3. 区分规则

| 如果这一步主要在说…… | 主小 pattern |
|---|---|
| 为什么不能只用确定性预报 | A |
| 预报以外的随机因素 | B |
| 选哪些来源、排除哪些 | C |
| 误差分布本身的形状或变化 | D |
| 误差之间的相关 | E |
| 怎样由有限信息得到误差分布 | F |
| 误差经过什么路径影响结果 | G |
| 误差大小如何改变决策 | H |
