# RP08 小 pattern：选择模型表示与求解方法

日期：2026-10-01 | 状态：已定稿 | 编码者：Claude Code | 方法同 [`RP01-families.md`](RP01-families.md)

**大 pattern 问题：** 怎样把这个调度问题变成一个算得动、又足够可信的模型？选哪种表示和哪种方法，理由是什么？

**证据：** RP08 的 38 步，均为 primary，来自 26 篇论文。逐条分配见 [`RP08-assignment.csv`](RP08-assignment.csv)。目前只编码了 primary 证据；其他步骤与 RP08 的 secondary 关系尚未编码。

**领域标签：** 按用户要求，每个小 pattern 都标注"领域特有"或"通用方法"，便于后续 B 组（通用科研技能）与 C 组（领域技能）的比较。

## 2. 小 pattern 定义

### RP08-A 水库系统的表示与计算取舍（领域特有）
- **触发条件：** 完整的水库与河道系统太复杂或太慢，无法直接放进优化或大量模拟中。
- **包含：**
  - 把梯级聚合成虚拟水库，并显式表示河道槽蓄（E44）；
  - MPC 内部用简化模型，外部用高精度水动力模型（E43）；
  - 按"精度与计算量"选择河道演算模型（E23）；
  - 对水位—库容、泄流曲线做局部线性化（E30、E31）；
  - 情景树的分支数和预见期（E35）；
  - 设计洪水频率取多少个（E41）；
  - 直接拟合预报产品，还是重跑整个预报链（E13）；
  - 用少参数风险曲线防止过拟合（E50）；
  - 选择可扩展的 MPC 框架（E17）。
- **识别后要做的事：** 说明保留了什么物理过程、简化了什么，以及简化对精度或风险估计可能造成什么影响；必要时做精度与计算量的对比测试。
- **预期产出：** 模型表示方案、接受的简化及其影响。

### RP08-B 解析推导路线（通用方法）
- **触发条件：** 问题结构允许用解析方法求最优解。
- **识别后要做的事：** 说明解析方法成立的条件，例如凸性、约束是否起作用；区分内部解和边界解。
- **代表证据：** E03-R6、E24-R4、E25-R4（"必须满足凸性，驻点才是最小值"）。

### RP08-C 求解与搜索算法的选择（通用方法）
- **触发条件：** 问题非线性、多目标或高维，无法直接求解。
- **识别后要做的事：** 说明为什么选这个算法，例如稳健、多样性、全局性；说明约束怎样处理，以及收敛或停止的标准。
- **代表证据：** E15-R6、E22-R6、E36-R5、E01-R7。

### RP08-D 不确定性与风险的计算方法（通用方法，用于水文问题）
- **触发条件：** 需要把不确定性传到水位和风险，或者由有限样本估计概率。
- **识别后要做的事：** 比较候选方法（模拟、一阶矩法、SDE、贝叶斯网络等）的长处和短处，说明所选方法保留了什么，例如相关性、尾部、因果结构。
- **代表证据：** E30-R2（选 SDE，而不是蒙特卡洛或 FOSM）；E32-R2（选动态贝叶斯网络）；E36-R7（样本太少，因此用最大熵）。
- **与 RP02-G 的边界：** RP02-G 判断"不确定性怎样传播"；RP08-D 判断"用什么方法来计算这种传播"。

### RP08-E 数据驱动预报模型的构建选择（通用方法，待定）
- **代表证据：** E14（事件分类、MIC 选输入、Cloud 模型组合）；E22-R2（选 LSTM 是因为速度快）。只有 2 篇论文。

### RP08-F 评价准则的处理方法（通用方法，待定）
- **代表证据：** E47（神经网络权重、一次改一个变量的敏感性分析）；E48（PCA、改进的熵权）。只有 2 篇论文。
