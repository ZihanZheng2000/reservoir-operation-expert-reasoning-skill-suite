# RP03 小 pattern：判断预报的可靠性与时效

日期：2026-10-01 | 状态：已定稿 | 编码者：Claude Code | 方法同 [`RP01-families.md`](RP01-families.md)

**大 pattern 问题：** 哪些预见期、哪些洪水阶段的预报，能支持哪些调度动作？

**证据：** RP03 的全部匹配，41 步、25 篇论文（primary 20，secondary 21）。逐条分配见 [`RP03-assignment.csv`](RP03-assignment.csv)。分组依据是"关于预报要做哪一种判断"。

## 2. 小 pattern 定义

### RP03-A 可靠性随预见期变化，按阶段使用预报
- **触发条件：** 预报误差随预见期增大，或者不同类型的预报（临近、短期、中期）可靠性不同。
- **识别后要做的事：** 划分"可靠预见期"，把远期粗预报用于准备，把近期定量预报用于具体放水；风险容忍度也随预见期调整。
- **预期产出：** 分阶段的预报使用规则（哪个预见期支持哪个动作）。
- **代表证据：** E10-R1（按误差 < 20% 定义可靠预见期）；E21-R3（2 周定性预报用于腾库，3–5 天定量预报用于错峰）；E07-R3（前 5 天风险容忍度为 0）。

### RP03-B 预报要来得够早，并选对指标
- **触发条件：** 腾库或预泄需要一定时间（泄流能力、爬坡速率、汇流时间），而预报的预见期可能不够；或者需要选一个更早、更贴合水库响应的预报变量。
- **包含：** 预见期决定可调的上限水位（E01、E35）；预见期与泄量、爬坡速率共同决定能否及时预泄（E17）；用水汽或降雨指标延长预见期（E19、E37）；按汇流时间选 6 小时径流指标（E27）；用多日洪量而不是洪峰作为预报对象（E11）。
- **识别后要做的事：** 比较"需要的响应时间"和"预报能提供的预见期"，必要时换用更早的指标或更保守的估计。
- **预期产出：** 所需预见期、所选的预报变量及其理由。
- **代表证据：** E35-R2、E19-R2、E27-R2。

### RP03-C 使用前先检验预报质量
- **触发条件：** 准备把某个预报产品用于调度或风险计算。
- **识别后要做的事：** 用历史预报检验精度（合格率、NSE、CRPS、秩直方图等），达到要求才使用；必要时先组合或校正预报。
- **预期产出：** 预报是否可用的结论及检验依据。
- **代表证据：** E18-R4（预报技能是筛选门槛）；E23-R2（先检验集合预报，再用于优化）；E28-R5（率定验证达到甲级后才用于规则）。

### RP03-D 预报精度不等于调度价值
- **触发条件：** 需要说明预报带来了多少调度收益。
- **识别后要做的事：** 不能只看技能分数；要用"无预报基线"和"完美预报"两个参照，并结合具体的调度响应来解释。
- **预期产出：** 预报价值的区间，以及剩余差距的原因（预报质量还是调度能力）。
- **代表证据：** E14-R5、E16-R6、E17-R6。

### RP03-E 由可接受风险反推所需的预报精度
- **触发条件：** 决策对预报误差大小敏感，或者已经给定了风险目标。
- **识别后要做的事：** 找出预报仍然有用的误差上限，或者由风险曲线反推最低精度要求。
- **预期产出：** "精度至少达到多少"的要求，或者"误差超过多少后不再有用"的阈值。
- **代表证据：** E28-R6（可接受风险 3×10⁻⁵ 对应 R² ≈ 0.85）；E05-R6（误差超过阈值后，蓄水已无意义）；E11-R2（保持设计洪水频率不变所允许的误差界）。
- **与 RP02-H 的边界：** RP02-H 关注误差大小如何改变决策分支；RP03-E 关注预报需要多准才能用。两者常同时出现。

### RP03-F 预见期之外和各库预见期不同（待定）
- **触发条件：** 调度时段比预见期长，或者梯级各库的预见期不同。
- **识别后要做的事：** 预见期内用预报情景，预见期外用设计洪水；按各库预见期之差对齐洪水过程。
- **代表证据：** E33-R2、E33-R3、E40-R2（只有 2 篇论文）。

### RP03-G 预报可能出错时如何使用它
- **触发条件：** 预报可能严重偏离实际，或者在极端暴雨中失效。
- **包含：** 按安全与效益结果选择预报分位数（E29）；按误差正负决定纠偏方向（E37-R7）；以实测为基础的后备规则（E46-R2）；用概率输入代替点预报来确定安全泄量界限（E15-R2）。
- **识别后要做的事：** 预先设计出错时的应对方式，例如保守取值、纠偏规则或后备方案。
- **预期产出：** 预报使用方式和失效时的应对规则。

## 3. 区分规则

| 主要在说…… | 主小 pattern |
|---|---|
| 不同预见期的可靠性不同 | A |
| 预报来得够不够早、选哪个指标 | B |
| 预报质量是否达标 | C |
| 预报值多少钱（价值），和技能分数的关系 | D |
| 需要多准，或误差的有用上限 | E |
| 预见期以外，或各库预见期不同 | F |
| 预报出错时怎么办 | G |
