# 05 - 小 pattern：每个大 pattern 内部的 104 个小 pattern

## 文件

| 文件 | 内容 |
|---|---|
| `reasoning/RP01–RP09-families.md`、`execution/EP01–EP11-families.md` | 每个大 pattern 一份：小 pattern 总览、逐个定义（触发条件、包含 / 不包含、识别后要做的事、预期产出、步数与论文数、代表证据），部分附区分规则 |
| `assign/<PID>.py` | 逐条分配：每条证据属于哪个小 pattern、副小 pattern、一句理由（RP01 另附每条证据的情境描述） |
| `reasoning/`、`execution/<PID>-assignment.csv` | 由 `assign/` 生成的分配表 |
| `build_assignments.py` | 校验分配是否覆盖了 `../03-step-coding/step-pattern-matches.csv` 中该大 pattern 的全部匹配，生成分配表，并输出每个小 pattern 的步数和论文数 |

复现：`python build_assignments.py`（生成全部 20 张分配表）。

## 方法（20 个大 pattern 相同，编码者：Claude Code，2026-10-01）

1. 取该大 pattern 的全部匹配（primary + secondary），逐条读取完整的步骤内容。
2. 用持续比较法分组。一个组能否成为独立的小 pattern，看三点：触发条件、识别后要做的事、预期产出是否不同。
3. 每条证据分配一个小 pattern（必要时加一个副小 pattern），并写一句只属于这一条的理由。已用脚本检查，每个文件里没有重复的理由，避免模板化。
4. 每个小 pattern 写出定义、步数、论文数和代表证据。
5. 证据强度：≥3 篇论文为成熟，2 篇为待定，1 篇为单例。
