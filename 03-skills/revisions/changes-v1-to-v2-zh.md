# Skill v1 → v2 修改记录

日期：2026-10-28 | 状态：已修改，未测试

## 依据与原则

- **用户决定（2026-10-28）**：
  - Haiku 的结果不再采用。理由是旧模型基本不具备独立做科研的能力，产出基本不可用。
  - 以 Opus 为主要依据，Sonnet 作参考。后续测试只跑 Opus。
  - 修改重点分三类：
    - (a) C 组比 A 组差或犯错的地方；
    - (b) 两组都漏掉、裁判反复指出的要点；
    - (c) U3–U6 这几道 C 没有稳定赢的题。
  - 报告中的 R1–R5 全部采纳。
- **证据来源**：`evidence/round-01-judge-extraction-opus-sonnet.md`。这份材料逐条整理了 opus 和 sonnet 的 28 份判定。下文写的"N/14"，是指 14 个"模型 × 题目"组合中出现该问题的组合数。
- **约束**：
  - 新增内容只来自裁判意见，每一条都标注了出处。
  - 新增的检查项用 J01–J22 编号，与 pattern 来源的检查项区分开。
  - 写法保持通用，适用于任何水库防洪调度问题，不针对开发题的具体答案。
- **保留不动的内容**：
  - v1 的 104 条 pattern 检查项全部保留，措辞未改。唯一的例外是 RP07-E，见下文。
  - 11 份 references 文件完全没有改动，已用 `diff` 核对。
  - 第一轮的所有结果都在 `05-round-01/`，没有覆盖。
