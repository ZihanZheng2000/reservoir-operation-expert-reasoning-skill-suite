## Paper identification

The paper addresses ranking feasible flood-control operation alternatives for a cascade system of reservoirs when performance criteria are correlated. Its topic relation is direct: the decision is a flood-control operation choice balancing reservoir safety and downstream protected-region safety. The case study is the Shuangjiangkou–Houziyan–Pubugou cascade in the Daduhe River basin, China. Page references use the supplied PDF page numbers.

## 2. How the authors reason

Reasoning overview: The paper frames cascade flood-control operation as a multi-criteria selection problem because no single alternative can optimize all conflicting objectives and because operation is dynamic and multi-stage (pp. 1–2). It therefore first defines measurable safety criteria for reservoirs and downstream protected regions. Because hydraulic connection makes criteria correlated, simply deleting criteria would lose distinct performance information and would not ensure independence; PCA is chosen to reduce dimensionality while retaining information (pp. 3–5). Improved entropy weighting is used because the conventional conversion can be unstable when entropy is close to one (pp. 5–6). Since no benchmark alternative is available, three different MCDM methods are run with and without PCA and their rankings are compared as a sensitivity/consistency check (p. 5). The case interpretation then favors a compromise that balances reservoir storage and downstream releases, while explicitly acknowledging that forecast, delay, and release uncertainties are omitted (p. 12).

Reconstructed route: frame the decision and competing safety objectives → define the hierarchical criteria → generate feasible cascade-operation alternatives → test correlation and reduce the criterion system with PCA → derive objective weights → rank alternatives through three MCDM procedures → compare PCA and non-PCA consistency → interpret the selected alternative against operational trade-offs and state deterministic limits.

## 3. How the authors execute

Execution overview: The study routes an actual upstream flood and interval flood events through a three-reservoir cascade under six combinations of three operation models. Each route produces 12 criterion values (three criteria for each of three reservoirs and three downstream-region criteria). The authors calculate correlations, standardize and transform the matrix with PCA, retain two components, compute improved entropy weights, and score the same alternatives with three MCDM methods. They compare scores with and without PCA and inspect the selected alternative’s criterion values and operating-model logic. The uncertainty discussion is a limitation branch rather than an executed stochastic analysis.

Reconstructed workflow: choose the Daduhe cascade and flood input → assign admissible model combinations → route the event under each combination using mass balance and safety constraints → assemble 12 criterion values → calculate correlations → normalize and run PCA → calculate entropy weights → run TOPSIS, fuzzy optimum, and fuzzy matter-element rankings with/without PCA → compare rankings and interpret alternative 6 → record deterministic limitation.
