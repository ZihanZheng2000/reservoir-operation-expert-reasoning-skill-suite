## Paper identification

The paper tests tree-based model predictive control (TB-MPC) for hourly flood control of the Yuvacik water-supply reservoir in Turkey. It synthesizes probabilistic streamflow forecasts (PSFs) from perturbed deterministic forecasts, represents them with a mass-conservative scenario tree, and repeatedly optimizes releases in closed-loop hindcasts. The central comparison is stochastic TB-MPC versus deterministic MPC using perfect forecasts or single deterministic forecasts, with downstream discharge/volume and end-of-event storage metrics.

## 2. How the authors reason

Reasoning overview: The authors view conventional guide-curve and deterministic MPC operation as vulnerable to forecast bias, especially for a limited-storage reservoir with a restricted downstream channel. Perfect-forecast MPC is used to determine how much forecast horizon is needed for timely pre-release; deterministic forecasts then show that a biased single trajectory can still produce releases above the 200 m³/s downstream threshold. The authors reason that probabilistic forecasts and multi-stage stochastic optimization should begin pre-release while representing the progressive resolution of uncertainty. A scenario tree allows control trajectories to branch only when uncertainty is resolved, reducing the infeasibility and excessive dimensionality that can arise from treating every ensemble member as a separate fully independent control sequence. The objective balances storage recovery, low spillway release, downstream-threshold penalties, guide-curve deviation, and gate-change smoothness. The claim stops at hindcast performance; synthetic forecast generation and tree settings are case-specific.

Reconstructed route: (1) identify forecast uncertainty and limited storage/downstream capacity as the control difficulty; (2) establish a perfect-forecast horizon reference; (3) demonstrate the failure mode of biased deterministic MPC; (4) synthesize flow-dependent, time-evolving PSFs; (5) reduce PSFs to a mass-conservative tree; (6) solve the tree-based stochastic control problem subject to water balance and hard physical limits; (7) apply only the root/current release and re-solve hourly; and (8) compare branch counts, horizons, flow return periods, independent forecast scenarios, and deterministic baselines.

## 3. How the authors execute

Execution overview: The study creates a 24-hour design flood hydrograph for a 100-year event and runs a 96-hour closed-loop hindcast with hourly decisions. At every hour, a single deterministic forecast is generated from the known hydrograph using a uniform ±0.3 relative error; 50-member PSFs are generated around that DSF with terminal relative standard error 0.2 and flow-dependent, nondecreasing uncertainty. For TB-MPC, the PSF members are reduced to a binary scenario tree (16 branches in the main configuration) using a mass-conservative tree-reduction process. A reservoir continuity model, piecewise-linear level-storage relation, spillway capacity, forebay bounds, and objective penalties are solved over the forecast horizon. Only the root release is applied, actual inflow updates the state, and the problem is solved again. Perfect, deterministic, and stochastic hindcasts are compared using final forebay elevation, peak outlet discharge, total downstream flood volume above 200 m³/s, and flood storage index (FSI), with extra tests over Q25, Q50, Q100 hydrographs and three independent randomized scenarios each.

Reconstructed workflow: The recurring loop is generate updated DSF/PSF → reduce PSFs to a tree → solve MPC → implement root spillway release → update storage with actual inflow → repeat. Horizon/branch sweeps and Q25/Q50/Q100 comparisons are evaluation branches; the perfect-forecast run is a reference setup.

## 6. Unreported or unresolved items

- The source text’s displayed DSF/PSF symbols are partly corrupted; the multiplicative DSF formula, PSF recursion, and qualitative flow-dependent update are recoverable, but some exact subscripts are unclear.
- Exact values of all objective weights (w_1ldots w_5), the variable guide curve, optimizer tolerances, and convergence/infeasibility handling are not reported.
- The mass-conservative tree-reduction algorithm is referenced to prior work; full distance/partition details and branch-selection automation are not reproduced.
- PSFs are synthetic normal/error-process constructions rather than calibrated operational ensemble forecasts. The selected terminal spread \hatσ₄₈=0.2 is chosen a posteriori by trial and error.
- The number of randomized forecast data sets is three per event condition, and the Q100 event is a design hydrograph; broader climate/forecast regimes are not tested.
- No explicit emergency override, operator authorization, fallback release action, or post-event learning procedure is reported.
- FSI, peak discharge, and flood volume are model indicators; downstream damage, human safety outcomes, and water-supply service reliability are not observed.
- The computational results are reported as total CPU seconds but hardware/software configuration and reproducibility inputs are incomplete.
- The study reports a future plan to use perturbed hydrological-model precipitation/temperature forcings; that extension is not executed in this paper.
