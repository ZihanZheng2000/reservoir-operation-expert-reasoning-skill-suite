# D2：论文路线覆盖（RC）

## 问题

skill 能不能让答案想到论文作者自己走的研究路线？

## 结果

- **图**：`figures/fig6-reference-coverage-matrix`（PNG 和 SVG）。
- **每个小方块图是一篇留出论文**（V01–V05）。
- **每一行**是这篇论文研究路线中的一个步骤，取自只给裁判看的 reference。
- **每一列**是一组答案：简单版 brief 的 A、C，详细版 brief 的 A、C。A = 不用 skill，C = 用 skill。
- **颜色**表示两位裁判认为这组答案有没有想到这一步：
  - 深蓝：想到了
  - 中蓝：用了合理的等价方法
  - 浅蓝：只想到一部分
  - 浅灰：没想到
  - 斜线格：两位裁判意见不一
- **每列底部的数字**：这组答案覆盖了多少个步骤（深蓝和中蓝都算）。

## 要点

1. **整行都是灰色的，就是谁都没想到**：多为论文自己的创新，例如 V01 的误差域、V03 的 RRCA 指标、V05 的紧凑系数。
2. **同一种 brief 下，C 列并不比 A 列更蓝**：skill 没有提高覆盖率。RC 平均分 A 6.7、C 6.6；简单版上 C 还略低，A 6.6、C 6.2。
3. **详细版的两列明显更蓝**：题目写得越详细，答案越接近论文的路线，这个影响比 skill 更大。
