# D4：多少篇论文能看到多少 pattern（累积曲线）

## 问题

我们从 50 篇论文中归纳出 20 个大 pattern 和 104 个小 pattern。如果只有 1 篇、5 篇或 20 篇论文，平均能看到其中多少个？要读多少篇，pattern 才算基本看全？

## 做法

不需要新跑 LLM，直接用 v3 已有的数据计算，结果可以复现。方法相当于生态学里的物种累积曲线（rarefaction）：

- **数据**：`../../02-patterns/05-small-patterns/{reasoning,execution}/*-assignment.csv`，即 1,074 条步骤—pattern 匹配，每条都已经分到了小 pattern。
- **计数规则**：
  - 大 pattern：一篇论文只要有一个步骤编码到某个大 pattern（primary 或 secondary 都算），就算这篇论文有这个大 pattern。口径与 `03-step-coding/pattern-coverage.csv` 相同。
  - 小 pattern：步骤所分到的小 pattern 和次要小 pattern都算。
- **抽样**：对 n = 1, 2, …, 50，每个 n 从 50 篇里随机抽 2,000 组（seed 20261029），每组数出现了多少个不同的大 pattern 和小 pattern，取平均值和 5–95% 区间。
- **估计还没见到的小 pattern**：用 Chao1 估计量，数出只在 1 篇论文中出现的小 pattern 个数（f1）和只在 2 篇中出现的个数（f2），估计语料再扩大时小 pattern 的总数：S + f1²/(2·f2)。

## 结果

| 论文篇数 | 大 pattern（共 20）：均值 [5–95%] | 小 pattern（共 104）：均值 [5–95%] |
|---:|---|---|
| 1 | 12.3 [9–16] | 17.9 [12–25] |
| 2 | 16.1 [13–18] | 31.9 [24–39] |
| 3 | 17.6 [15–20] | 43.1 [35–51] |
| 5 | 18.7 [17–20] | 59.6 [51–68] |
| 10 | 19.3 [18–20] | 81.2 [74–88] |
| 15 | 19.5 [19–20] | 91.3 [85–97] |
| 20 | 19.6 [19–20] | 96.6 [91–101] |
| 30 | 19.9 [19–20] | 101.3 [97–104] |
| 40 | 20.0 [20–20] | 103.2 [101–104] |
| 50 | 20.0 [20–20] | 104.0 |

- **一篇论文**平均用到 12.3 个大 pattern、17.9 个小 pattern，约占大 pattern 的 60%、小 pattern 的 17%。
- **大 pattern 很快饱和**：5 篇就能看到约 19 个（94%），10 篇看到 19.3 个。
- **小 pattern 要多得多**：5 篇只能看到约 60 个（57%），20 篇约 97 个（93%），30 篇约 101 个（97%），基本看全要 40 篇左右。
- **小 pattern 已经接近饱和**：只出现在 1 篇论文里的小 pattern 只有 2 个，只出现在 2 篇里的有 10 个。Chao1 估计总数约为 104.2，也就是说，在这个研究主题内，再多读论文也不太可能出现很多新的小 pattern。

## 对讨论的意义

1. **样本量的依据**：50 篇论文足以覆盖这个主题的大 pattern 和小 pattern。如果只要大 pattern 一级的框架，5–10 篇就够了；要细到小 pattern，至少需要 20–30 篇。
2. **单篇论文只用到一部分**：一篇论文平均只涉及约 12 个大 pattern。这说明 skill 里的单元不会在每个问题上都用到，也支持"按需取用单元"的设计（skill 的第 4 步）。
3. **对"证据少的 pattern"的提醒**：小 pattern 曲线在 20 篇时仍在上升。如果语料少，一些小 pattern 根本看不到，而它们在实际中可能很重要（例如梯级相关的 pattern，见 D1 和 human review 例 2）。

## 局限

- **只是在已有分类里数**：曲线回答的是"n 篇论文中能看到现有 20 个大 pattern、104 个小 pattern 中的多少个"，而不是"只用 n 篇论文重新归纳，会得到多少个 pattern"。后者要用 n 篇论文从头重新归纳 pattern，需要重跑 LLM 和人工改写，成本高、也难复现，这里没有做。
- **一次提取会漏**：D1 显示一次提取大约漏掉 19% 的 pattern 出现。所以每篇论文的 pattern 数是下限，曲线实际会更早饱和。
- **只能外推到同一主题**：50 篇论文都是"洪水风险下的水库调度"，Chao1 估计只适用于这个主题。

## 复现

```bash
python accumulation.py <v3 文件夹> <输出文件夹>      # 例如：python accumulation.py ../.. .
```
