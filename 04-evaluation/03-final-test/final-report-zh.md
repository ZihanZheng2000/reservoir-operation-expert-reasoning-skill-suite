# 最终测试报告：skill v3，V01–V05 留出论文

日期：2026-10-29。测试方案见 `protocol.md`（运行前写定）。原始结果见 `results.md`，裁判意见见 `judgments/`。

## 测试设置

- **答题**：Claude Opus 5.5。A 组不用 skill，C 组用 skill v3（冻结版本）。
- **论文**：5 篇留出论文，没有参与 pattern 和 skill 的构建。每篇有两种 brief：
  - S：简单版，两段话；
  - D：详细版，5 个模块。
- **评判**：
  - 每个 case（论文 × brief 版本）由 2 位 Opus 5.5 裁判盲评，两人看到的答案顺序相反。
  - 裁判读 brief、reference（论文实际采用的研究路线）和两份答案，不读论文原文。
  - 评分有 6 项：KQ（关键问题）、TC（技术正确性）、ME（方法）、PR（可操作性）、CA（结论是否有据）、RC（是否覆盖论文路线）。
  - 两位裁判都判同一方胜，才算该方赢。

**要点**：
- **留出论文上 skill 稳定胜出**：A 一个 case 都没赢。V01-D 和 V05-D 有 clear（明显胜出）票。
- **提升最大的是 PR（+1.6）**，其次是 KQ（+0.7）和 ME（+0.6）。
- **RC 没有提升**：全部平均 6.7 对 6.6；简单版上 C 反而低（6.2 对 6.6），详细版上略高（7.0 对 6.8）。
- **CA 略低**（8.0 对 8.2）。
- **C 的答案长 32%**。

## 二、RC 为什么没有提升（详见 `rc-analysis-zh.md`）

1. **差异大多在裁判噪声范围内**：
   - 20 份判定中，C 的 RC 低于 A 的有 6 份，高于 A 的 4 份，相同的 10 份。
   - 在 C 较低的 6 份里，有 4 份同一 case 的另一位裁判判两者相同。
   - 只有 V03-D（两位裁判都给 C 较低）和 V05-D（都给 C 较高）方向一致。
2. **两组共同的上限**：两组都没覆盖的要点，大多是论文自己的设计。例如：
   - V01 的"误差域"；
   - V02 的 GA 逐步调整权重；
   - V03 的 RRCA 指标和 stacking 集成预报；
   - V04 的奇偶时段插值；
   - V05 的紧凑系数 γ。

   这些对 A 和 C 一样难，所以两组 RC 都停在 6–7 分。
3. **brief 的详细程度比 skill 的影响更大**：从简单版到详细版，C 的 RC 提高 0.8，A 只提高 0.2。不少 reference 要点只在详细版中出现，两组都一样：V01 的 Pθ、V04 的六种误差假设对照、V05 的分频率规则集。
4. **skill 把答案推向通用的严谨性和可操作性**：
   - C 的 10 份答案都写了影子运行，都写了相关误差方差公式。
   - 这些内容在 PR、ME 上得到了回报，但 RC 不计分。
   - C 的 RC 较低的那几份判定里，扣分点集中在**优化与形式化层面写得更空**：多目标求解器、情景聚合（regret 或 worst-case）、目标项清单。裁判在这几份里都没有指出 C 写了错误内容。
5. **一句话**：skill 教会了"按专家流程把关"，但没有教"像论文作者那样提出方法层面的问题"。

## 三、skill 引起的错误（需要记录）

**J02 的公式被套错了**：
- J02 给出的是等相关时的公式：nσ²(1+(n−1)ρ)。
- C 组把它用在了逐时自相关（AR(1) 型）的误差上，夸大了累积误差。例如 V04-S-C 算出 "24 h 体积误差的标准差是独立时的 4.4 倍"。
- 裁判在 V03-D、V04-S、V04-D 中指出了这个问题。
- 这是 skill 内容直接造成的模板化错误。按方案，最终测试之后不再修改 skill；如果后续继续迭代，应改为"按误差的实际自相关结构计算"。

## 四、和以前的最终测试对比（仅作参考）

旧版测试（2026-10-09，旧 skill，700 词、四节固定格式，答题模型未记录）的结果：
- C 5 胜 0 负，10/10 判定偏向 C；
- 平均分 6.93 → 7.53；
- RC 6.3 → 6.3。

答案格式、模型和 brief 都不同，不能直接比较。但"skill 赢、RC 不变"这个规律两次测试都出现了。

## 五、对研究问题的回答

1. **skill 在留出论文上是否胜过不用 skill？** 是。8 个 case 胜出，0 个输，18/20 份判定偏向 C，平均分 +0.48，主要来自 PR、KQ 和 ME。
2. **简单版上的优势是否更大？** 否。两种 brief 上胜负完全相同（各 4/0/1）；平均分差距简单版 +0.42，详细版 +0.55。
3. **RC 是否提升？** 否，简单版上还略低。skill 带来的是流程和可操作性，而不是覆盖论文的方法路线。

## 六、后续可以考虑的方向（不在本次测试范围内）

`rc-analysis-zh.md` 第 5 节从 reference 中整理出 19 个"通用、可迁移、论文作者在思考时自然会问"的问题，可以作为下一版 skill 补充方法层面思考的候选。例如：

- 用决策空间而不是流量空间评价预报误差；
- 权重是否应随水文状态变化；
- 一个方案在多个情景上的表现如何聚合成一个值；
- 新指标要做消融实验；
- 用一组由简到繁的误差假设，量化简化假设会把风险低估多少。

同一节也列出了论文特有、不应写进 skill 的内容。这些候选来自留出论文的 reference，如果要用，需要另找新的留出论文做测试，否则这 5 篇就不再是留出测试了。
