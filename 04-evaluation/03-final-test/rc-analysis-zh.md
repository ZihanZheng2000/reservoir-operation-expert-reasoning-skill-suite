## 4. 判断

- **(a) 论文特有的创新**：成立，但只解释了一部分。两组共同的上限来自这类内容。
- **(c) 其他原因**，占比很大：
  - 裁判噪声；
  - brief 的详细程度比 skill 影响更大；
  - RC 奖励"贴合论文路线"，等价替代也只给部分分。
- **(b) skill 让答案偏向通用内容**：只在简单版上明显。
  - C 的 10 份答案都写了相关误差方差公式和影子运行。
  - 这些内容在 PR 上得到了回报：简单版 C 9.0 对 A 7.3，详细版 8.9 对 7.3。
  - 但在 C 的 RC 较低的判定里，方法设计层确实写得更空。
- **J02 公式被套用错误**：等相关公式被用在 AR(1) 型的逐时误差上。裁判在 V03-D、V04-S、V04-D 中指出了这个问题。

## 5. 可考虑补进 skill 的通用问题，以及不应补进的内容

### 5.1 通用、可迁移的问题

1. 用决策空间而不是流量空间评价预报误差：哪些误差不会改变决策？（来自 V01）
2. 该信哪个预见期的预报？能否逐日按状态自适应选择？都不可信时如何回退？（V01）
3. 有效预见期 = 预见期 − 决策和执行延迟。（V01）
4. 权重和参数应该固定，还是随水文状态变化？要与分别调向各个极端目标的固定基线对比。（V02）
5. 量纲不同的目标如何归一化？关键权重要做敏感性分析。（V02）
6. 非凸目标和非线性曲线如何进入实时求解器？例如分层：可解的近似模型 + 完整评估器。（V02）
7. 全过程库容利用：同时惩罚"过险"和"过保守"。（V03）
8. 一个方案在多个情景上的表现如何聚合成单一值：期望、分位数、worst-case 还是 regret？（V03）
9. 新提出的指标或目标要做消融实验。（V03）
10. 用一组由简到繁的误差假设，量化简化假设会把风险低估多少。（V04）
11. 决策变量的编码会不会产生锯齿这类不可运行的解？（V04）
12. 跨水库的目标是否可比，例如水位和剩余库容？（V04）
13. 鲁棒方法的计算成本是否满足实时要求？（V04）
14. 哪种过程线形状或历时最危险，用什么准则挑选？（V05）
15. 基线要同时包括原设计规则和现行规则。（V05）
16. 决策变量用运行人员熟悉的形式表达，例如开 / 关水位。（V05）
17. 预报期是否覆盖决策真正需要的时间尺度？（V05）
18. 把不同分布之间的差异作为认知不确定性来报告。（V05）
19. 两种方向的预报退化都要测试：精度要求放宽，以及误差放大。（V01）
